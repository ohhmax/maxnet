SSL Root CA Certificate Guide
Authority: MAXNET Root CA
TLS 1.3 TRUSTED
To eliminate all browser "Not Secure" warnings when opening https://maxnet.local or https://10.0.0.1, install the MAXNET Root CA certificate on your phone or PC once.
1. Android (Chrome & Web Browsers)
1. Tap Download Root CA button below.
2. Go to phone Settings → Security & Privacy → More Security → Encryption & Credentials.
3. Tap Install a Certificate → CA certificate → Install anyway.
4. Select the downloaded maxnet-root-ca.crt file. Done!
2. Windows (Chrome, Edge, Firefox)
1. Download maxnet-root-ca.crt and double-click to open it.
2. Click Install Certificate... → Current User or Local Machine.
3. Select Place all certificates in the following store.
4. Browse and choose Trusted Root Certification Authorities → Click Finish!
3. Apple iOS & iPadOS (iPhone, iPad, Safari)
1. Tap APPLE 1-TAP (.MOBILECONFIG) button below → Tap Allow in Safari.
2. Go to Settings → Profile Downloaded → Install.
3. Go to Settings → General → About → Certificate Trust Settings.
4. Under "Enable full trust for root certificates", toggle MAXNET Root CA to ON. Done!
